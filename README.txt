EXPENSE TRACKER - FLUTTER STARTER

WHAT IS INCLUDED
- Add an expense with title, amount, category and date.
- See the total of all expenses.
- View a simple chart of spending over the last 7 days.
- See recent transactions.
- Swipe a transaction from right to left to delete it.
- Undo a deletion using the SnackBar action.

HOW TO USE
1. Create a Flutter project:
   flutter create expense_tracker

2. Open the new project folder.

3. Replace its lib folder with the lib folder in this package.

4. Run:
   flutter pub get
   flutter run

IMPORTANT
This starter uses only Flutter's built-in libraries; no extra packages are required.
The sample expenses and newly added expenses are stored in app memory only.
They will reset when the app is fully closed. Add SQLite or SharedPreferences later
if you want expenses to remain saved after restarting the app.
